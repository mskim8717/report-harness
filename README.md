# report-harness — 보고서 작성용 하네스 실습

감사연구원 AI 활용 교육 3일차 「보고서 작성용 하네스」 실습 폴더입니다. Claude Code가 이 폴더의 규칙(`CLAUDE.md`)과 절차(스킬)를 따라, 공식 원문에서 확인한 사실만 근거표에 적고, 위키로 정리한 뒤, 출처가 붙은 보고서 초안을 씁니다.

## 받기

터미널을 열고 아래 세 줄을 한 줄씩 넣고 Enter를 누릅니다.

```
git clone https://github.com/mskim8717/report-harness.git
cd report-harness
claude
```

- `git`이 없다는 메시지가 나오면: 이 페이지 위쪽 **Code → Download ZIP**으로 받아 압축을 풀고, 폴더 이름을 `report-harness`로 바꿔 홈 폴더에 둡니다.
- `claude`를 넣었을 때 아래쪽에 입력창이 뜨면 됩니다. 처음 열 때 이 폴더를 신뢰하는지 물으면 신뢰한다고 답합니다.

영국 NAO 원문 PDF는 저작권 조건 때문에 저장소에 넣지 않았습니다. 아래 「실습 시나리오」 2단계에서 공식 사이트에서 각자 받습니다.

## 폴더

```
report-harness/
├── CLAUDE.md              규칙: 폴더·파일 이름·근거표와 위키 형식·보고서 형식
├── .claude/skills/
│   ├── collect-official-sources/   해외 감사기구 자료 수집 (원문 → 근거표 → 위키)
│   ├── collect-nabo-budget/        국회예산정책처 예산 자료 수집
│   └── write-report-section/       보고서 초안 쓰기 (위키 → 보고서)
├── .claude/agents/
│   ├── source-verifier.md          검토 담당자: 근거표 한 행을 원문과 대조
│   └── report-reviewer.md          평가 담당자: 보고서 초안을 여섯 기준으로 채점
├── .claude/settings.json  sources/ 수정 금지 · 공식 사이트 읽기 허용
├── sources/               공식 원문 (읽기 전용, 폴더마다 _출처.md)
├── brief/                 의뢰서 — 템플릿과 예산 주제 의뢰서
├── evidence/  wiki/  report/   근거표 · 위키 · 보고서 초안 (스킬이 만든다). report/_보고서_템플릿.md는 초안의 머리·뼈대
├── tools/check_evidence.py     근거표 형식 검사
└── 교재/실습_시나리오.md   다섯 단계 실습 시나리오와 예시 요청문
```

## 실습 시나리오 (수강생은 말로 요청만 한다)

자세한 판과 막힐 때의 대응은 `교재/실습_시나리오.md`에 있습니다. 같은 다섯 단계를 해외 감사기구 자료와 국회예산정책처 자료로 두 번 돕니다.

**1단계 · 설치.** 터미널에서 `claude`를 켜고 요청합니다.

> https://github.com/mskim8717/report-harness 를 clone해서 그 폴더로 들어가고, CLAUDE.md를 읽고 이 하네스에서 누가 무엇을 만드는지 설명해줘.

**2단계 · 자료 수집** (원문 → 근거표).

먼저 저장소에 없는 NAO 원문을 공식 주소에서 받습니다(저작권 조건 때문에 각자 받습니다). 확인 창이 뜨면 허용합니다.

> 영국 NAO의 AI 전략 PDF를 공식 주소 https://www.nao.org.uk/wp-content/uploads/2026/08/The-NAOs-AI-Strategy.pdf 에서 받아 sources/해외감사기구/The-NAOs-AI-Strategy.pdf 로 저장해줘. 다른 파일은 고치지 마.

그다음 수집을 요청합니다.

> GAO, NAO, ECA 같은 해외 감사기구가 감사 업무에 AI를 어떻게 쓰고 무엇을 계획하는지 공식 자료를 수집해줘. 기관마다 근거 2건 이상.

Claude가 `brief/`에 의뢰서 초안을 만들어 보여 주고(기관·질문·근거 수·보고서 절) 확인을 받은 뒤, `sources/` 원문을 읽어 근거표 `evidence/<주제>.md`를 만듭니다. 사실 1건이 표 1행이고 행마다 원문 URL·쪽·확인 상태가 붙습니다. 카파시 LLM 위키의 raw sources 층입니다.

**3단계 · 위키로 구조화** (근거표 → 위키).

> 근거표를 위키로 정리해줘. 원문 목록, 기관별 확인된 사실, 비교와 시사점, 재확인 필요로 나눠서. 목차(index)도 갱신해줘.

`wiki/<주제>.md`와 `wiki/index.md`가 생깁니다. 사실은 근거표에 있는 것만 옮기고, 해석은 `작성자 해석` 표시가 붙어 `## 비교와 시사점`에만 있습니다.

**4단계 · 보고서 초안** (위키 → 보고서).

> 나는 「주요국 최고감사기구의 AI 운영 현황 및 시사점」 보고서를 쓰고 싶어. 개조식으로 초안을 완성해줘.

위키와 근거표만 읽고 `report/<주제>.md`를 씁니다. 사실 문장 끝마다 근거 번호 `[E-1]`이 붙고, 시사점은 `□ (시사점·작성자 해석)` 한 곳에만 있습니다.

**5단계 · 평가** (하네스의 핵심).

> report-reviewer에게 report/해외감사기구_AI활용.md 를 CLAUDE.md 평가 기준으로 채점하게 하고 점수표를 보여줘.

평가 담당자가 여섯 항목을 채점합니다. ① 모든 사실 문장에 근거 번호가 있는가 ② 근거표에 없는 수치·연도가 없는가 ③ 표본 행을 원문과 대조해 일치하는가 ④ 상태·기준일·단위가 문장에 남아 있는가 ⑤ 해석이 시사점 한 곳에만 있는가 ⑥ 형식(개조식 계층·표 캡션·자료 줄)이 맞는가. 통과하지 못한 항목은 다음 요청으로 고칩니다.

> 실패한 항목을 고쳐줘. 사실이 틀렸으면 근거표부터 고치고 위키·보고서에 반영해. 바꾼 줄만 알려줘.

다시 평가해 여섯 항목이 모두 통과하면 보고서 초안 완성입니다. 같은 실패가 두 번 생기면 CLAUDE.md 사실 기록 원칙에 규칙 한 줄을 더합니다.

**2회차.** 같은 다섯 단계를 국회예산정책처 자료로 돕니다. 의뢰서 `brief/국회예산정책처_AI예산.md`는 미리 들어 있고, 4단계에서 "부처별 표를 넣어" 요청하면 〈표 1〉이 든 초안이 나옵니다.

## 원문 자료와 이용 조건

| 폴더 | 파일 | 이용 조건 |
| --- | --- | --- |
| `sources/해외감사기구/` | GAO AI Strategy (2026-08), Artificial Intelligence at GAO 웹 페이지 저장본, ECA Artificial Intelligence strategy 2026-2030 | GAO: 미국 GAO 저작물, 출처 표시 · ECA: CC BY 4.0(출처 표시·변경 표시) |
| `sources/국회예산정책처/` | 2026년도 예산안 총괄 분석 Ⅲ, NABO Focus 제132호 | 공공누리 제1유형(출처표시) |

- 영국 NAO의 「The NAO's AI Strategy」는 NAO 저작권 조건(연구·개인 학습용 복제만 허용) 때문에 이 저장소에 넣지 않았습니다. 위 「받기」의 문장으로 공식 사이트에서 각자 받습니다.
- PDF를 쪽 단위로 읽으려면 poppler(pdftoppm)가 필요합니다. GAO·ECA·국회예산정책처 PDF는 `_텍스트/` 추출본이 있어 없어도 읽지만, 수업 중 각자 받는 NAO PDF는 18쪽이라 쪽 지정 읽기가 필요하고 저작권 조건상 추출본을 둘 수 없습니다. **수업 전에 설치해 둡니다.** macOS `brew install poppler`, Windows `scoop install poppler` 또는 `choco install poppler`, Ubuntu `sudo apt install poppler-utils`. 터미널에서 `pdftoppm -v`가 버전을 보여주면 됩니다.
- 파일별 URL·발행일·출처 표시 문구는 각 폴더의 `_출처.md`에 있습니다. 이 저장소는 각 기관의 후원·보증을 받지 않았습니다.

## 근거표 형식 검사(선택)

Python이 있으면 근거표의 열·근거 번호·URL·위치·확인 상태 어휘를 검사할 수 있습니다. 사실이 원문과 맞는지는 검사하지 않습니다.

```
python3 tools/check_evidence.py
```
