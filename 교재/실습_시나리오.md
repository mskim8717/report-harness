# 실습 시나리오 · 한 문장으로 보고서 완성하기

수강생은 Claude Code에 **말로 요청**하고, 질문 창이 뜨면 고릅니다. 규칙은 `CLAUDE.md`, 절차는 스킬, 평가는 검토 담당자가 맡습니다. 어떤 주제든 흐름은 같습니다.

## 1단계 · 설치

터미널을 열고 `claude`를 켠 뒤 요청합니다.

> https://github.com/mskim8717/report-harness 를 clone해서 그 폴더로 들어가고, CLAUDE.md를 읽고 이 하네스에서 누가 무엇을 만드는지 설명해줘.

보는 것: `sources/`(공식 원문) → `evidence/`(근거표) → `wiki/`(위키) → `report/`(보고서 초안) 네 층, 그리고 마지막의 평가.

## 2단계 · 시작과 방향 잡기

쓰고 싶은 보고서를 한 문장으로 말합니다.

> 나는 주요국 최고감사기구의 AI 운영 현황 및 시사점 보고서를 쓰고 싶어.

또는 자료부터 말해도 됩니다.

> 해외 감사기구의 AI 활용 관련 자료를 수집할 수 있을까?

Claude가 질문 창으로 묻습니다. 요청문에 이미 있는 것은 묻지 않습니다.

| 질문 | 고르는 것 |
| --- | --- |
| 자료원 | 해외감사기구(GAO·NAO·ECA) / 국회예산정책처 / 자료가 있는 기관·공식 사이트 주소를 직접 알려주기 |
| 보고서가 답할 질문 | 제안 2~3개 중 하나, 또는 직접 작성 |
| 기간 | 최근 2년 / 특정 연도 / 전체 |
| 형식 | 개조식 / 서술식, 표 포함 여부 |
| (필요할 때) | 자료원별 최소 근거 수, 보고서 절 제목, 예산 자료면 예산안·확정 구분과 지정 표 |

답하면 `brief/<주제>.md` 의뢰서를 만들어 보여 주고 "그대로 진행 / 고칠 곳 있음"을 묻습니다. 저장소에 없는 원문은 이때 공식 주소에서 받아 `sources/`에 넣고 `_출처.md`에 기록합니다. 영국 NAO PDF가 그 예입니다(저작권 조건 때문에 저장소에 넣지 않음). 확인 창이 뜨면 허용합니다.

## 3단계 · 수집과 위키

"그대로 진행"을 고르면 자동으로 이어집니다.

- 근거표 `evidence/<주제>.md`: `sources/` 원문을 열어 사실 1건을 표 1행으로. 행마다 상태·기준일·단위, 원문 URL, 쪽(또는 절·표), 확인 상태.
- 위키 `wiki/<주제>.md`: 원문 목록, 자료원별 확인된 사실, 비교와 시사점(작성자 해석 표시), 재확인 필요. 목차 `wiki/index.md`에 1줄 추가.
- 열지 못한 원문(OECD처럼 사이트가 자동 접근을 막는 경우)은 사실 행 없이 `## 재확인 필요`에만 남습니다. 이것이 의도한 동작입니다.

확인할 것:

> 근거표 3번 행의 원문 쪽을 열어 그 문장을 그대로 보여줘.

## 4단계 · 초안

위키와 근거표만 읽어 `report/<주제>.md`를 씁니다. `report/_보고서_템플릿.md`의 머리와 뼈대를 따르고, 사실 문장 끝마다 근거 번호 `[E-1]`이 붙으며, 시사점은 `□ (시사점·작성자 해석)` 한 곳에만 있습니다.

확인할 것:

> 보고서 첫 ○ 문장이 근거표 몇 번 행이고 원문 몇 쪽인지 열어서 보여줘.

## 5단계 · 평가 (하네스의 핵심)

`report-reviewer`가 `CLAUDE.md` 「평가 기준」 여섯 항목으로 채점한 점수표를 보여 줍니다.

| 항목 | 묻는 것 |
| --- | --- |
| ① 근거 연결 | 사실 문장마다 근거 번호가 있는가 |
| ② 근거표 밖 수치 없음 | 보고서의 수치·연도·기관이 모두 근거표에 있는가 |
| ③ 원문 일치 | 표본 행을 원문과 대조했을 때 사실·수치·단위가 그대로인가 |
| ④ 상태·기준일·단위 | 운영 중/시범/계획, 예산안/확정과 기준일·단위가 문장에 있는가 |
| ⑤ 해석 분리 | 작성자 해석이 시사점 한 곳에만 있고 사실과 섞이지 않았는가 |
| ⑥ 형식 | 개조식(제N절·□·○·-, 명사형)·표 캡션·단위·자료 줄·템플릿 머리가 맞는가 |

실패 항목은 근거표 → 위키 → 보고서 순서로 고치고 다시 평가합니다. 6/6이면 초안 완성입니다. 같은 실패가 두 번 생기면 이렇게 요청합니다.

> 같은 문제가 두 번째 생겼다. 다시 생기지 않도록 CLAUDE.md 사실 기록 원칙에 한 줄만 추가해줘.

## 다른 주제도 같은 문장으로

> 나는 2026년도 기관별 AI 예산 현황 보고서를 쓰고 싶어. 부처별 표를 넣어줘.

자료원으로 국회예산정책처를 고르면 예산 자료 특례가 적용됩니다. 예산안과 국회 확정은 다른 행, 금액은 원문 단위 그대로, 보고서 표에서만 환산하고 환산 기준을 단위에 적습니다. 평가에서는 특히 ②(예산안과 확정을 섞지 않았는가)와 ④(단위·기준일)를 봅니다.

## 막힐 때

- NAO PDF를 받지 못하면 NAO 사실 행이 없이 `재확인 필요`에 남고, GAO·ECA로 계속 진행합니다.
- PDF 쪽을 읽지 못한다는 메시지가 나오면 poppler가 없는 것입니다. GAO·ECA·국회예산정책처 자료는 `_텍스트/` 추출본으로 읽히고 NAO만 못 읽습니다. 설치 방법은 README에 있습니다.
- OECD 자료를 요청하면 사이트가 자동 접근을 막아 원문을 열 수 없다고 나옵니다. 사실 행을 만들지 않는 것이 맞는 동작입니다.
