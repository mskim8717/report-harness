# 보고서 하네스 진입 스킬

사용자가 "~보고서를 쓰고 싶어", "~관련 자료를 수집할 수 있을까", "~현황 보고서 초안", "~분석 보고서"라고 하면 이 스킬로 시작한다. 자료 수집만 말했어도 끝은 보고서이므로 같은 흐름으로 간다(보고서를 쓸지는 2차 질문에서 확인). 규칙은 `CLAUDE.md`, 의뢰서 양식은 `brief/_의뢰서_템플릿.md`, 보고서 뼈대는 `report/_보고서_템플릿.md`를 따른다.

이번 요청: $ARGUMENTS

## 1. 방향 잡기 (AskUserQuestion)

요청문에서 알 수 있는 것(주제어, 기관, 형식)은 미리 채우고, **모르는 것만** 묻는다. 한 번에 최대 4문항, 보통 두 번이면 끝난다. 사용자가 이미 말한 것을 다시 묻지 않는다.

1차 질문(방향):
- 자료원: `sources/` 폴더 목록을 선택지로 보여 준다(예: 해외감사기구 GAO·NAO·ECA, 국회예산정책처). 여러 개 선택 가능. 주제에 맞는 저장 원문이 없거나 사용자가 다른 자료를 원하면 **"자료가 있는 기관과 공식 사이트 주소를 알려 달라"**고 묻는다. 사용자가 준 주소는 공식 도메인인지 확인하고, `.claude/settings.json` 허용 목록에 없으면 WebFetch 확인 창이 뜬다는 점을 알린다(계속 쓸 도메인이면 사용자 동의 아래 허용 목록에 추가).
- 보고서가 답할 질문: 요청문으로 2~3개를 제안하고 고르게 한다(예: "각 기관은 감사 업무에 AI를 어떻게 쓰고 무엇을 계획하는가").
- 기간: 최근 2년(기본) / 특정 연도 / 전체.
- 형식: 개조식(조사연구 기본) / 서술식(기반연구), 표 포함 여부.

2차 질문(세부, 필요할 때만):
- 자료원별 최소 근거 수: 2(기본) / 3 / 5.
- 보고서 절 제목: 질문을 줄인 제안 1~2개 + 사용자 작성.
- 예산·통계 자료면: 예산안과 확정을 모두 다루는지, 읽을 표가 정해져 있는지(지정 표), 보고서 표의 단위·환산.
- 자료 수집만 요청했으면: 근거표·위키까지만 할지, 보고서 초안까지 쓸지.

## 2. 의뢰서 작성과 확인

답을 `brief/_의뢰서_템플릿.md` 양식으로 `brief/<주제>.md`에 쓴다. 주제 이름은 CLAUDE.md 명명 규칙(`<자료원>_<주제어>`, 예: `해외감사기구_AI활용`). 공식 시작 링크와 저장된 원문은 `sources/<폴더>/_출처.md`에서 옮긴다. 의뢰서를 보여 주고 AskUserQuestion으로 "그대로 진행 / 고칠 곳 있음"을 확인받는다.

## 3. 원문 확보

의뢰서의 원문이 `sources/`에 있으면 그대로 쓴다. 없으면 공식 도메인(`.claude/settings.json` 허용 목록)에서 받아 `sources/<폴더>/`에 원본 파일명으로 저장하고 `_출처.md`에 행(URL·발행·받은 날·이용 조건)을 추가한 뒤 사용자에게 알린다. 받지 못한 원문(접근 차단·저작권)은 사실 행을 만들지 않고 위키 `## 재확인 필요`에 남긴다. 저장 원문을 하나도 열지 못하면 `수집 중단: 공식 원문 접근 불가`로 보고하고 멈춘다.

## 4. 수집 → 위키

`collect-sources` 스킬의 절차로 `evidence/<주제>.md`와 `wiki/<주제>.md`를 만들고 `wiki/index.md`에 1줄을 더한다. 끝나면 근거표 행 수와 `## 재확인 필요` 항목을 보고하고 `python3 tools/check_evidence.py evidence/<주제>.md`를 돌린다.

## 5. 초안

`write-report-section` 스킬의 절차로 `report/<주제>.md`를 쓴다. 쓰고 나서 CLAUDE.md 「평가 기준」 ①(모든 사실 문장에 근거 번호)·⑥(개조식 마침표 없음, 템플릿 머리)을 스스로 한 번 점검한다.

## 6. 평가와 수정

`report-reviewer` 서브에이전트에게 채점을 맡겨 점수표를 사용자에게 보여 준다. 실패 항목은 근거표 → 위키 → 보고서 순서로 고치고 바꾼 줄을 보고한 뒤 다시 평가한다. 6/6 통과까지 최대 2회 반복하고, 그래도 남으면 남은 항목과 이유를 사용자에게 넘긴다. 같은 항목이 두 번 실패하면 CLAUDE.md에 규칙 한 줄을 더할지 사용자에게 묻는다.

## 마치면

의뢰서·근거표·위키·보고서 경로, 근거 행 수, 평가 점수, `## 재확인 필요` 항목, 새로 `sources/`에 받은 원문을 한 번에 보고한다.
